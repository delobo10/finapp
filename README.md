# FinApp - Sistema de Gestão Financeira Pessoal

Sistema completo de gestão financeira com React, TypeScript, Supabase e integração com Telegram Bot.

## 🚀 Tecnologias

- ⚛️ React 18 + TypeScript
- 🎨 Tailwind CSS
- 📊 Recharts (gráficos)
- 🗄️ Supabase (backend + autenticação)
- 🤖 Telegram Bot (comandos por mensagem)
- 📱 Responsivo

## ✨ Funcionalidades

- ✅ Controle de receitas e despesas
- ✅ Categorias personalizáveis
- ✅ Orçamentos mensais com alertas
- ✅ Metas financeiras
- ✅ Relatórios e gráficos
- ✅ Transações recorrentes
- ✅ Notificações de orçamento
- ✅ Bot do Telegram
- ✅ Exportação de dados (PDF/CSV)
- ✅ Previsão de tendências

## 🔐 Segurança

- Autenticação via Supabase
- Row Level Security (RLS)
- Dados isolados por usuário

## 📦 Deploy

Deploy automático via Vercel conectado ao GitHub.
